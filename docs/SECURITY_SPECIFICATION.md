# SECURITY SPECIFICATION (direction)
- No secrets in Git: `.env`, `config/local.json`, keys ignored; only `.env.example` committed. Credentials via env vars/OS credential store.
- Server binds 127.0.0.1 by default; LAN exposure requires explicit config and, from Phase 20, an auth token.
- Spend control: $0–5 auto, $5–25 auto within configured rules, $25+ human approval; enforced in code (Phase 12/20).
- Human escalation for legal, account-threatening or dangerous situations.
- Emergency stop halts all agents and outbound actions (Phase 20).
- Default-deny agent permissions; audit trail append-only. Phase 3: external capabilities (publish/spend/communicate/configure) cannot be granted; agent configs and task payloads reject credential-like keys; API validates IDs/bodies and returns no paths or secrets; demo endpoints are disabled in production. Phase 4: the Supervisor has no network, process or eval access (tested by source scan); it dispatches only tasks an agent is permitted to run and the runtime re-checks permissions; decisions never contain payloads or credentials; supervisor API validates `kind`/`since`/`limit`, exposes no paths or instance ids; pause/resume controls are demo-only (403 in production). Real approvals/human control remain Phase 20. Phase 5: observability endpoints are GET-only; every filter is whitelisted, length/format-validated and bound as an SQL parameter (no column names or fragments from input); limits ≤ 200, time ranges ≤ 30 days; responses and logs are sanitized (credential-like keys redacted, paths/stack traces removed, strings truncated); health/metrics expose no filesystem paths; the observability module contains no network, process, timer or write code (enforced by a source-scan test).
- Compliance: no copying protected IP, no spam, obey marketplace ToS; QA/IP checks gate publishing.
- Treat all fetched web content as untrusted input.
- Logs must redact secrets.

### Phase 6 (AI providers)
Credentials (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`) are read only from the environment (or the git-ignored `.env`, loaded without overriding real variables) and held in provider objects; they are never in the config object, status API, events, logs, errors, task payloads or metadata. Errors from providers are reduced to a category plus a redacted, bounded message (key shapes, `Authorization`/`x-api-key` values, `Bearer` tokens, passwords, exact configured secrets and file paths are scrubbed). A prompt containing a configured credential is refused before sending. Prompts and outputs are not persisted. Endpoints must be https (http only for localhost), without credentials, query or fragment; redirects are rejected; response bodies are size-capped; every call has a timeout and honors cancellation. Request fields are whitelisted and bounded (input chars, output tokens, timeout cannot exceed the configured one, schema size, no credential-like keys in schemas, ids validated). The `ai` capability is required to run AI tasks and is never given to demo agents; `mock` is refused in production; Freebuff cannot be selected. Cost ceilings fail closed. No spending, purchasing, account creation or marketplace access exists.

### Phase 7 (Research Engine) — network and content policy
- **Everything fetched is untrusted input.** Pages are parsed as text only: no JavaScript execution, scripts/styles/iframes/comments removed, content type allowlist (html, xhtml, plain, markdown, json, xml), no file/shell access, no cookies/auth headers, `Accept-Encoding: identity`, no recursive crawling (only URLs returned by discovery are fetched, once each).
- **URL policy** (`urlsafe.js`, tested): only `https:` (plain `http:` only to explicitly enabled loopback test infra); credentials in URLs rejected; ports limited to 80/443 unless configured; IP literals incl. decimal/hex/IPv6/IPv4-mapped/NAT64/6to4 are classified; loopback, RFC1918, CGNAT, link-local (incl. cloud metadata 169.254.169.254), multicast, documentation/reserved ranges and internal names (`localhost`, `.local`, `.internal`, single-label hosts) are blocked by default. `allowLoopback`/`allowPrivateNetworks`/`allowHttp` are explicit config flags (`RESEARCH_ALLOW_LOCALHOST=1` enables loopback+http for local test infrastructure); link-local/metadata/reserved addresses can never be enabled.
- **DNS**: all A/AAAA answers are checked before the request (any blocked answer blocks the host), and the node transport re-checks at connect time through a guarded `lookup`, closing the DNS-rebinding window. Every redirect hop is re-validated (scheme, credentials, port, address); HTTPS→HTTP downgrades and more than 3 redirects are refused.
- **Limits**: timeout 8 s, response ≤ 1 MB (stream cut off mid-transfer), extracted text ≤ `maxTextChars`, per-run source/retrieval/time/AI budgets, cancellation via AbortSignal.
- **Robots/ToS**: `robots.txt` is fetched once per origin and honored (disallow → not fetched; unreachable/5xx → treated as disallowed). 401/402/403 are reported as `access_denied`; paywalls, logins and CAPTCHAs are never bypassed.
- **Errors/logs/events** never contain credentials, URL query strings, page text, prompts or model output; retrieval errors carry fixed safe messages.
- **API**: no arbitrary-URL fetch endpoint; objective schema is strict (unknown fields rejected, secrets rejected, size-bounded); read endpoints bounded and parameterized.
- **Prompt injection**: page text sent to a model is delimited and labelled untrusted; model output is schema-validated, evidence ids must exist, confidence is capped, and the model can take no action (it only returns findings).
- **Capabilities**: `source_retrieval` is the only new external capability (network read); there are no publish/spend/communicate capabilities in research.

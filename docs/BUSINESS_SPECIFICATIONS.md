# BUSINESS SPECIFICATIONS
Modules live in `businesses/<name>/`. All are plugins on the shared Agent OS. Not implemented until their phase.

## 1. Etsy / POD Factory (Phase 8)
Research popular/high-selling items → analyze demand and competition (incl. newer high-performing sellers) → find trends and gaps → generate ORIGINAL designs from market intelligence → quality/IP/similarity checks → pick POD provider → create listing → publish via legitimate automation → monitor → optimize.
Constraint: never copy protected competitor artwork. Future upgrade: advanced competitor intelligence.

## 2. Game Asset Factory (Phase 9)
Asset types: sprites, characters, environments, tilesets, backgrounds, props, UI, icons, concept art, asset packs, other 2D. Excluded initially: VFX, sound, music. Research reputable marketplaces and high-demand niches. Future upgrade: game templates.

## 3. Affiliate Network (Phase 10)
Find currently popular/profitable opportunities → practical programs with reasonable access requirements → choose publishing destinations by audience activity and click potential → original useful content → publish to multiple legitimate sites → monitor traffic, clicks, conversions → optimize. Future upgrade: automated niche-site creation. Must have rate/quality controls; no spam.

## 4. Fiverr Creative Studio (Phase 11)
Research demand → create gigs → portfolio examples → pricing → detect orders → interpret requirements → thumbnails/creative → QA → deliver → handle normal revisions → autonomous customer communication → optimize. Dangerous, legal or account-threatening situations escalate to a human.

## Cross-cutting
Shared: research, tasks, providers, automation, logging, finance, analytics, recovery, safety, progression. Every publish/spend passes QA/safety and the approval gate.
